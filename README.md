# Antonella Roggio — Portfolio

Portfolio personal desarrollado para presentar la trayectoria profesional, formación académica, habilidades y proyectos de Antonella Roggio, diseñadora especializada en diseño, comunicación y experiencia de usuario.

## Descripción

Sitio web personal que reúne información sobre el perfil profesional, la formación académica y los conocimientos técnicos de la diseñadora, junto con una selección de trabajos y medios de contacto.

El diseño busca ofrecer una experiencia visual atractiva, con una identidad gráfica propia y una navegación sencilla.

## Características

- **Presentación personal:** perfil, experiencia profesional e intereses.
- **Formación académica:** títulos, estudios y certificaciones.
- **Habilidades profesionales:** conocimientos en diseño gráfico, diseño web y experiencia de usuario.
- **Portfolio:** espacio destinado a mostrar trabajos y proyectos.
- **Formulario de contacto:** permite enviar consultas mediante un formulario.
- **Redes sociales:** enlaces a perfiles profesionales y personales.
- **Diseño responsive:** adaptación de la interfaz a diferentes tamaños de pantalla.
- **Navegación fluida:** desplazamiento suave entre las secciones del sitio.

## Tecnologías utilizadas

- HTML5 para la estructura del sitio.
- CSS3 para los estilos y la identidad visual.
- Bootstrap para la maquetación responsive y los componentes de interfaz.
- JavaScript para las interacciones y funcionalidades.
- jQuery para la manipulación de elementos y la interacción con la página.
- Font Awesome para los iconos.
- Google Fonts para las tipografías.
- PHP para los componentes del proyecto relacionados con el servidor.

## Instalación y ejecución

El proyecto utiliza tecnologías web tradicionales y no requiere un proceso de compilación.

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/mati-romero/AntonellaRoggio.git
   ```

2. Ingresar al directorio del proyecto:

   ```bash
   cd AntonellaRoggio
   ```

3. Abrir `index.html` en un navegador web o utilizar la extensión Live Server de Visual Studio Code para visualizar el sitio durante el desarrollo.

**Nota:** si se necesita probar el envío del formulario de contacto, será necesario configurar un servidor compatible con PHP y verificar los archivos correspondientes de la carpeta `php`.
